## 功能

把 B站 和 微博 的更新自动推送到 QQ 群，推送内容自带精美卡片配图。

- **B站直播**：开播 1~2 秒内推送，WebSocket 实时监听
- **B站动态**：图片、文字、专栏、转发、视频投稿，自动转成卡片图
- **微博动态**：支持长文、多图、转发
- **直播间查询**：状态、在线人数、最近弹幕
- **订阅列表**：一键生成图片，带头像
- **推送控制**：@全体、@指定成员、按类型过滤、单独开关下播/改标题
- **四种直播卡样式**：随机切换，每次推送都不一样

所有命令都是中文，不需要记参数。

> 插件只在「订阅对象有更新」时发言，正常聊天不会误触。

## 命令

### 所有人可用

| 命令 | 说明 |
|---|---|
| `#订阅列表` | 查看本群订阅了谁 |
| `#订阅帮助` | 命令速查 |
| `#直播间 1017` | 查直播间状态和最近弹幕 |

### 订阅与取消

| 命令 | 说明 |
|---|---|
| `#订阅动态 253298645` | 订阅 B站 UP 主动态 |
| `#订阅直播 1017` | 订阅 B站直播（房间号或 UID 都行） |
| `#订阅微博 2700162334` | 订阅微博博主 |
| `#取消订阅动态 253298645` | 取消对应订阅 |
| `#取消订阅直播 1017` | |
| `#取消订阅微博 2700162334` | |

同一个号可以同时订阅直播和动态，互不影响。

### 推送开关

默认开播、下播、改标题都会推送。想单独关掉某个 UP 的某一类：

| 命令 | 说明 |
|---|---|
| `#关闭下播推送 1017` | 这个 UP 下播不推 |
| `#开启下播推送 1017` | 恢复 |
| `#关闭改标题推送 1017` | 这个 UP 改标题不推 |
| `#开启改标题推送 1017` | 恢复 |

### @全体

| 命令 | 说明 |
|---|---|
| `#推送@全体 直播 1017` | 这个 UP **开播**时 @全体 |
| `#推送@全体 动态 253298645` | 这个 UP **发动态**时 @全体 |
| `#推送@全体 动态 2700162334` | 这个微博博主发文时 @全体 |
| `#取消@全体 直播 1017` | 取消对应类型 |
| `#查看@全体` | 查看本群配置 |

- 直播和动态分开配置，互不影响
- 同一对象 **2 小时内只 @ 一次**，避免频繁上下播刷屏
- 需要机器人为群管理员，否则 QQ 不允许 @全体
- 下播和改标题不会 @全体

### @指定成员

不想 @全体时，可以 @ 特定的人：

| 命令 | 说明 |
|---|---|
| `#@成员 1017 12345678` | 这个 UP 推送时 @ 指定的人 |
| `#取消@成员 1017 12345678` | 取消 |
| `#查看@成员` | 查看本群配置 |

一次可以填多个：`#@成员 1017 1111 2222`

### 动态过滤

| 命令 | 说明 |
|---|---|
| `#动态过滤 253298645 not_type 转发` | 不推转发动态 |
| `#动态过滤 253298645 type 投稿 专栏` | 只推这两类 |
| `#动态过滤 253298645 not_text 抽奖 广告` | 不推含这些词的 |
| `#动态过滤 253298645 text 抽奖` | 只推含这些词的 |
| `#动态过滤 253298645 show` | 查看当前规则 |
| `#动态过滤 253298645 clear` | 清空规则 |

支持的类型：转发、投稿、专栏、文字、图片、音频、直播分享

### 私聊使用

私聊时在命令后面加 `-g 群号` 即可操作指定群：

```
#订阅直播 1017 -g 123456789
#订阅列表 -g 123456789
#关闭下播推送 1017 -g 123456789
```

## 安装

### 1. 放进插件目录

把整个 `Subscribe-Push` 文件夹放到 Yunzai 的 `plugins/` 下：

```
TRSS-Yunzai/
└── plugins/
    └── Subscribe-Push/
```

重启 Yunzai，看到这行日志就说明加载成功：

```
[订阅推送] 已启动，订阅 N 项
```

### 2. 准备 Cookie

B站动态和微博动态需要登录态，插件通过 [CookieCloud](https://github.com/easychen/CookieCloud) 自动获取。

复制 `config/server.example.json` 为 `config/server.json`，填好账号：

```json
{
  "cookieCloud": {
    "endpoint": "http://127.0.0.1:8088",
    "uuid": "你的uuid",
    "password": "你的password"
  }
}
```

没有 CookieCloud 的话，也可以手动放 Cookie 文件到 `data/cookies/` 下，命名 `Bili_Cookies.json` 和 `Weibo_Cookies.json`。

### 3. 开始订阅

在群里直接发命令即可，不需要改配置文件：

```
#订阅直播 1017
#订阅动态 253298645
```

## 常见问题

**为什么刚订阅没有收到历史内容？**

首次订阅只记录当前状态作为基线，不会补发历史动态或历史开播。这是刻意设计，避免刷屏。之后有新内容才会推送。

**为什么 @全体 没生效？**

需要把机器人设为群管理员，否则 QQ 不允许机器人 @全体。另外同一对象 2 小时内只会 @ 一次。

**推送的图出不来？**

插件复用 Yunzai 自带的 puppeteer 浏览器截图。如果日志提示 Chromium 相关错误，执行：

```bash
node node_modules/puppeteer/install.js
```

**微博提示未配置 Cookie？**

检查 `config/server.json` 的 CookieCloud 配置，或确认 `data/cookies/Weibo_Cookies.json` 是否存在且未过期。

**B站动态提示 -101 账号未登录？**

B站 Cookie 过期了，在 CookieCloud 里重新同步一次。

**数据会丢吗？**

不会。订阅数据存在 `data/subscriptions.json`，每次写入都是原子操作，并且保留了最近 10 个备份在 `data/backup/` 里。换机器时复制整个 `data/` 目录就能带走全部订阅。

**支持哪些平台？**

目前支持 B站（直播 + 动态）和微博。抖音、小红书等暂不支持。
